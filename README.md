# NOVA Launcher

A personal Android home-screen launcher with a minimal AMOLED-black interface, electric-blue accents, live clock/date, and a searchable list of installed apps.

## Build
Every push to `main`, or a manual workflow run, builds a debug APK with GitHub Actions. Download the `NOVA-Launcher-APK` artifact from the Actions run.

## Install on Android
Download the workflow artifact, extract it, and install `app-debug.apk`. If Android asks, allow installation from your browser or file manager. Then choose **NOVA Launcher** as the Home app, or set it under **Settings → Apps → Default apps → Home app**.

This is a personal sideload build, not a Play Store release.
